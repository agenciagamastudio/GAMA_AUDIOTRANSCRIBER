## Description

Create visual moodboards that inspire design decisions:
- Photography style (what kind of images do we use?)
- Color mood (how do colors feel together?)
- Illustration style (are illustrations part of our brand?)
- Layout inspiration (clean vs. dense?)
- Texture & patterns (do we use textures?)

4 categories:
1. Professional (corporate, serious)
2. Creative (playful, experimental)
3. Educational (clear, instructive)
4. Community (human, relatable)

Output: /brandbook/moodboard/ with curated image grid

---

## Acceptance Criteria

- [ ] 4 moodboard categories created
- [ ] 8-12 images per category (curated or designed)
- [ ] Photography style defined (modern, minimalist, warm, cool?)
- [ ] Color combinations shown in context
- [ ] Illustration examples (if applicable)
- [ ] Each category has brief explanation
- [ ] Images are high quality and on-brand
- [ ] Responsive grid layout

---

## Scope

### IN (What's included)
- 4 visual moodboard categories
- 8-12 curated images per category
- Photography style documentation
- Color mood exploration
- Illustration style examples
- Category descriptions and guidance
- Responsive grid layout
- High-quality image assets

### OUT (What's NOT included)
- Creating original photography or illustrations (use stock/existing)
- Licensing negotiations (use free or licensed assets)
- Detailed design system component examples (separate story)
- Animation or motion inspiration (separate story)

## Implementation Notes

- Use stock imagery platforms for sourcing (Unsplash, Pexels, etc.)
- Ensure all images align with Gama brand aesthetic
- Each category should tell a story about how Gama appears in different contexts
- Include brief explanation for each category explaining the use case
- Responsive grid ensures good viewing on all devices
- Consider accessibility for image descriptions
