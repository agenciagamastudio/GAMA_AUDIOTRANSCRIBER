---

## Description

Create pre-built sections for rapid page construction:
- Hero (banner + CTA)
- Feature grid (3-col, 4-col)
- Testimonial carousel
- Pricing table
- FAQ accordion
- Call-to-action block
- Team grid
- Image gallery
- Form sections
- Stats showcase

Each section: light mode + dark mode, responsive, accessible.

---

## Acceptance Criteria

- [ ] 10+ sections implemented
- [ ] Each section responsive (mobile, tablet, desktop)
- [ ] Light + dark mode for each
- [ ] Accessibility (WCAG AA minimum)
- [ ] Easy component props (color, title, content)
- [ ] Copy-paste ready code
- [ ] Storybook stories for each
- [ ] TypeScript props defined

---

## Scope

### IN (What's included)
- 10+ pre-built section components
- Responsive design (mobile-first approach)
- Light and dark mode variants
- WCAG AA accessibility compliance
- Customizable props (easy to use)
- TypeScript prop definitions
- Storybook documentation
- Copy-paste ready code examples
- Tailwind CSS styling

### OUT (What's NOT included)
- Custom content personalization
- CMS integration or backend
- Complex animation sequences
- A/B testing framework
- SEO-specific optimizations beyond standards

## Dependencies

**Blocks:** GAMA-DS-3.6 (templates use these sections)

## Implementation Notes

- This is the most complex story - use @apex-lead Frontend Squad (14 agents)
- Consider parallel implementation of different section types
- Each section should have multiple variants (e.g., Hero with background image, solid color, etc.)
- Props should be intuitive (title, subtitle, cta_text, cta_link, etc.)
- Light/dark mode should be automatic via CSS variables
- Responsive grid should adapt at standard breakpoints (640px, 1024px, 1280px)
- Test with various content lengths (short copy, long copy)
- Include image aspect ratio guidance for galleries
- Form sections should include validation examples
