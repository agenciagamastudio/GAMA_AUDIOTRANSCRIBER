## Description

Create templates for 6 social platforms:
- Instagram (square, story, reel sizes)
- Twitter/X (16:9, text-focused)
- LinkedIn (document-style, carousel)
- TikTok (vertical video notes)
- YouTube thumbnail (16:9)
- Slack (profile banner)

All branded with Gama aesthetic.

- [ ] Brand guidelines applied
- [ ] Figma file with variants

### IN (What's included)
- 6 social media platform templates
- Correct platform dimensions
- Gama brand aesthetic applied
- Figma design file with variants
- PNG template exports
- 3+ example posts per platform
- Copy suggestions and headlines

- Accessible color contrast

### OUT (What's NOT included)

- Actual social media posting

## Implementation Notes

- Can start in Week 3 once GAMA-DS-2.1 provides brand strategy direction
- Instagram: 1080x1080 (post), 1080x1350 (story), 1080x1920 (reel)
- Twitter/X: 1200x675 (16:9 ratio)
- LinkedIn: 1200x627 (document), multiple slides for carousel
- TikTok: 1080x1920 (vertical video)
- YouTube: 1280x720 (thumbnail)
- Slack: 800x200 (profile banner)
- Figma should have components for easy customization
- PNG exports ready to add text, images, etc.
- Include brand color variations
- Consider both light and dark theme versions
