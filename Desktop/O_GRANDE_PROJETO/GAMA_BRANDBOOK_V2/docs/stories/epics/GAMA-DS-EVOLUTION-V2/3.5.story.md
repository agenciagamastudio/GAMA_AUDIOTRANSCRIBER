## Description

Create a motion library with 5+ animations:
- Fade in (on scroll, on mount)
- Slide in (from left, right, top, bottom)
- Scale (grow, shrink)
- Bounce (elastic effect)
- Rotate (spin, subtle rotate)

Document with code, Figma prototypes, and performance tips.
Provide Framer Motion variants for easy reuse.

---

## Acceptance Criteria

- [ ] 5+ animations documented
- [ ] Framer Motion code provided
- [ ] Configurable duration & easing
- [ ] Performance: no janky animations (60fps)
- [ ] Accessibility: respects prefers-reduced-motion
- [ ] React hook for each animation (usefadeIn)
- [ ] Figma interactive components
- [ ] Usage examples (when to use which animation)

## Scope

### IN (What's included)
- 5+ animation implementations
- Framer Motion library integration
- Configurable duration and easing options
- React hooks for easy component integration
- Performance optimization (60fps target)
- Accessibility compliance (motion preferences)
- Figma interactive prototypes
- Usage guidelines and examples
- Copy-paste ready code snippets

### OUT (What's NOT included)
- Page transitions or routing animations
- Complex choreographed sequences
- 3D or WebGL animations
- SVG animation specifically (CSS animations are OK)
- Game-like interactive animations

## Implementation Notes

- Framer Motion is the recommended library for React animation
- All animations must maintain 60fps performance (use GPU acceleration)
- prefers-reduced-motion must be respected (disable animations if set)
- Provide both spring and timing animations for different use cases
- React hooks make it easy to reuse animations in components
- Figma prototypes help designers understand motion behavior
- Include examples: fade-in on mount, slide-in on scroll, scale on hover, etc.
- Document easing curves and when to use each
- Test animation performance with DevTools
- Consider staggered animations for multiple elements
