## Description

Migrate design tokens to 3 priority projects:
1. GAMA_CALCULADORA
2. GAMA_FINANCEIRO
3. GAMA_MONITOR

For each project:
- Install tokens from gama-ds-platform
- Update all color references
- Test light/dark mode toggle
- Document any custom tokens
- Train team on token updates

- [ ] Tokens installed in all 3 projects
- [ ] All color references updated
- [ ] Light/dark mode works
- [ ] No breaking UI changes
- [ ] Tokens documented per project
- [ ] Team training completed
- [ ] Migration verified by @architect

## Scope

### IN (What's included)
- Token package installation in 3 projects
- Color reference updates
- Light/dark mode implementation
- Breaking change identification and resolution
- Documentation per project
- Team training and handoff
- @architect verification and approval
- Migration timeline: 1 project per week

### OUT (What's NOT included)
- Migrating to remaining 6 projects (Phase 2)
- Creating new custom tokens
- Redesigning UI based on new tokens
- Performance optimization beyond token usage
- Analytics integration
