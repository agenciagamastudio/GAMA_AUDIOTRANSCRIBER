## Description

Create reusable visual patterns:
- Dot grid (repeating dots)
- Line patterns (horizontal, vertical, diagonal)
- Noise texture (grayscale, colored)
- Scanlines (CRT effect, optional)
- Glass pane frame
- Border treatments (custom borders)
- Grid overlays

Provide SVG, PNG, and CSS versions.
Show use cases (as background, overlay, border).

- [ ] Use case examples (background, overlay, border)

## Scope

### IN (What's included)
- 7+ visual pattern definitions
- SVG format provision
- PNG export for reference
- CSS generation methods and patterns
- Use case documentation
- Tiling and seamless implementation
- Performance optimization
- Customization guidelines
- Figma library assets
- Interactive pattern generator (optional)

### OUT (What's NOT included)
- Animated patterns (static only)
- Custom pattern generation tools (UI library only)
- Applying patterns to specific components
- Texture optimization beyond PNG standard
- Print specifications

## Implementation Notes

- Use CSS patterns (repeating-linear-gradient) for lightweight implementation
- SVG allows for scalable, crisp patterns
- Ensure patterns tile seamlessly without visible seams
- Optimize PNG files for web (compression)
- Document color customization for each pattern
- Test performance impact when used as backgrounds
- Provide both small (16px) and large (32px) tile options
- Include accessibility considerations (not too distracting)
- Figma library makes it easy for designers to use
