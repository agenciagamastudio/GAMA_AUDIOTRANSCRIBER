# Story GAMA-DS-3.2 — /ds/effects — Visual Effects (VFX) Library

## Overview

---

## Description

Create a library of visual effects:
- Glassmorphism (frosted glass effect)
- Glow effect (#88CE11 green glow)
- Grain/noise texture
- Blur backdrop
- Shadow variants (depth levels)
- Gradient overlays
- Blend modes showcase

Provide CSS, Tailwind utilities, and React hooks.
Document performance impact.

---

## Acceptance Criteria

- [ ] 6+ effects documented
- [ ] CSS variables for easy customization
- [ ] Tailwind config classes (e.g., @apply glass-effect)
- [ ] React hook for each effect (useGlassEffect)
- [ ] Performance tested (GPU acceleration)
- [ ] Accessibility checked (not distracting, contrast OK)
- [ ] Browser compatibility (Chrome, Firefox, Safari)
- [ ] Code examples (copy-paste ready)

---

## Scope

### IN (What's included)
- 6+ visual effects implementation
- CSS custom properties for customization
- Tailwind CSS integration and utilities
- React hooks for easy component integration
- Performance optimization and GPU acceleration
- Accessibility compliance (prefers-reduced-motion)
- Cross-browser testing and documentation
- Copy-paste ready code examples
- Interactive effect showcase

### OUT (What's NOT included)
- WebGL or canvas-based effects
- Video or animated effects (static CSS only)
- Real-time rendering effects
- Custom effect creation beyond 6 specified
- Animation timing and transitions (separate story)

---

## Dependencies

**Blocks:** None (can be used independently)
**Blocked By:** GAMA-DS-1.1

## Implementation Notes

- Glassmorphism should use backdrop-filter with proper fallbacks
- Glow effect uses #88CE11 to match brand
- All effects must respect prefers-reduced-motion for accessibility
- Test performance with GPU profiling tools
- Provide Tailwind config that can be imported
- React hooks make integration seamless for developers
- Include performance impact documentation for each effect
- Ensure effects work in dark mode
- Browser compatibility: target modern browsers (Chrome 90+, Firefox 88+, Safari 15+)
