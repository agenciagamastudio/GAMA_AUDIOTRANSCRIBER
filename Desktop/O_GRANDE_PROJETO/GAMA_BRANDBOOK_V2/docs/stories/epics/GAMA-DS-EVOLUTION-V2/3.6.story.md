## Description

Create 3 complete page templates using components + sections:
1. Marketing landing page (hero + features + CTA)
2. Dashboard (header + sidebar + grid layout)
3. Documentation (sidebar + content + TOC)

Each template: fully responsive, accessible, themeable.
Code examples for Next.js integration.

## Implementation Notes

- This story depends on completion of sections (3.4) and charts (3.1)
- Each template should showcase real-world usage patterns
- Use existing components from previous stories heavily
- Responsive breakpoints: 640px (mobile), 1024px (tablet), 1280px (desktop)
- Theming should work via CSS variables (light/dark mode automatic)
- Next.js example should use new App Router (not Pages Router)
- Performance target: Lighthouse > 85 on all templates
- Test with actual content (real text, images)
- Figma library makes it easy for designers to create new pages
- Include SEO basics (meta tags, structured data)
