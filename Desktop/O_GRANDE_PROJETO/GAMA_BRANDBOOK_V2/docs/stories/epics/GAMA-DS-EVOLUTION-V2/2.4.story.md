## Description

Define the icon system for Gama:
- Icon grid & sizing (16px, 24px, 32px, 48px)
- Stroke width & consistency (2px, 1.5px?)
- Corner radius (sharp vs. rounded?)
- Color application (primary, monochrome?)
- 30+ icons documented (system core set)
- Usage guidelines (when to use which icon)

Output: /brandbook/icons/ with interactive icon library

---

## Acceptance Criteria

- [ ] Icon grid defined (16, 24, 32, 48px)
- [ ] Stroke width consistent across all icons
- [ ] Corner radius rule applied consistently
- [ ] 30+ icons in Gama style available
- [ ] Each icon has name, use case, SVG code
- [ ] Color variants shown (primary, monochrome, semantic)
- [ ] Usage guidelines clear ("Use 24px for buttons, 32px for hero")
- [ ] Searchable/filterable by category

---

## Scope

### IN (What's included)
- Icon system design and specification
- 30+ core icon set
- Multiple size variants (16, 24, 32, 48px)
- SVG format provision
- Color variant documentation
- Usage guidelines and best practices
- Interactive icon library/browser
- Category filtering and search functionality
- Accessibility documentation

### OUT (What's NOT included)
- Custom icon creation beyond the 30 core set
- Animated icons (static only)
- Logo or brand mark variations (covered in story 2.2)
- Icon font generation (SVG format only)

## Implementation Notes

- Consistent stroke width and corner radius create cohesive system
- 30+ icons should cover common UI patterns (navigation, actions, notifications)
- Interactive library helps designers discover and use icons
- SVG format allows easy customization and scaling
- Include both primary color and monochrome variants
- Semantic color variants (success, error, warning, info) for status icons
- Search/filter functionality essential for discoverability
