## Description

Create chart components for business intelligence:
- Bar chart (horizontal, vertical, stacked)
- Line chart (multi-series, area, smoothed)
- Donut/Pie chart
- KPI card
- Progress bar (linear, circular)
- Heat map
- Trend indicator

Use Recharts or D3.js, styled with Gama tokens.
Interactive examples with code snippets.

---

## Acceptance Criteria

- [ ] 7+ chart types implemented
- [ ] All use Gama color palette (#88CE11 accent)
- [ ] Responsive to mobile (< 600px)
- [ ] Accessibility: alt text, ARIA labels
- [ ] Code examples for React integration
- [ ] Storybook stories for each variant
- [ ] Performance: render < 500ms
- [ ] Documentation with use case guide

### OUT (What's NOT included)

## Implementation Notes

- Recharts is recommended for easier integration and accessibility
- #88CE11 (Gama green) should be primary accent in charts
- Consider data visualization best practices (color-blind friendly)
- Interactive examples with Recharts Tooltip and Legend
- Performance target of <500ms render is critical for dashboards
- Test with large datasets to ensure performance holds
- Include light and dark mode variants
- Document when to use each chart type
