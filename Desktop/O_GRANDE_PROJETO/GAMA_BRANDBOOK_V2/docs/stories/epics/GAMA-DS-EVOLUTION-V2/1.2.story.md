## Description

Research all 5 Gama brands (studio, tv, radio, calendar, financeiro).
Extract from existing projects:
- Brand philosophy, mission, values
- Logo variants (color, white, icon)
- Color palette (primary, secondary, semantic)
- Tone of voice (how we talk)
- Visual patterns observed

Consolidate into:
- brand-data.json (structured)
- brand-audit.md (narrative)
