## Description

Create the strategic foundation:
- Mission statement (expanded from extracted data)
- Vision statement
- Brand archetype (who are we?)
- Positioning statement (vs. competitors)
- Core values (3-5)
- Brand voice & personality
- Principles (what guides us)

Output: /brandbook/movimento/index.md (interactive page)

---

## Acceptance Criteria

- [ ] Mission statement clear and inspiring
- [ ] Vision statement 5-10 years out
- [ ] Brand archetype defined (Hero, Sage, Lover, etc.)
- [ ] Positioning unique vs. competitors
- [ ] 3-5 core values defined
- [ ] Voice & personality documented (tone, language, vocabulary)
- [ ] 5-7 brand principles listed
- [ ] All sections have brief explanation of "why"
